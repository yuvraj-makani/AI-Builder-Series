# 🖼️ Image Explorer Pro

> A beginner-friendly Computer Vision project built using **Python, OpenCV, NumPy, and Matplotlib** to explore image properties and perform basic image processing operations.

---

## 📌 Overview

Image Explorer Pro is a mini Computer Vision project developed as part of my **AI Builder Series**.

The project allows users to:

- Load an image
- Display the image
- Extract image metadata
- Analyze pixel statistics
- Visualize RGB channels
- Convert the image to grayscale
- Generate a negative image
- Save all processed outputs

This project helped me understand how images are represented as **NumPy arrays** and how OpenCV performs basic image processing operations.

---

## ✨ Features

- 📂 Load images using OpenCV
- 🖼️ Display images using Matplotlib
- 📊 Extract image information
  - Width
  - Height
  - Channels
  - Shape
  - Data Type
  - Total Pixels
- 🔍 Pixel Statistics
  - Minimum Pixel Value
  - Maximum Pixel Value
- 🌈 RGB Channel Visualization
- ⚫ Grayscale Conversion
- 🎭 Negative Image Generation
- 💾 Save processed images

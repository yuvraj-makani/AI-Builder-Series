# 🖼️ OpenCV-EdgeLab

A beginner-friendly Computer Vision project built using **Python**, **OpenCV**, **NumPy**, and **Matplotlib** as part of the **AI Builder Series**.

This project demonstrates fundamental image smoothing and edge detection techniques commonly used as preprocessing steps in Computer Vision applications.

---

# 🚀 Features

- 📂 Load Image
- 🖼️ Display Original Image
- 🌫️ Gaussian Blur
- 🎯 Median Blur
- ✨ Bilateral Filter
- 🧠 Canny Edge Detection
- 💾 Save Processed Images

# 📸 Output Preview

### Original Image

Original image loaded using OpenCV.

---

### Gaussian Blur

Reduces image noise using a Gaussian kernel.

---

### Median Blur

Replaces every pixel with the median value of its neighboring pixels.
Highly effective for removing Salt & Pepper Noise while preserving edges.

---

### Bilateral Filter

Smooths the image while preserving object boundaries.
Widely used before segmentation and edge detection.

---

### Canny Edge Detection

Detects strong edges by performing:

- Noise Reduction
- Gradient Calculation
- Non-Maximum Suppression
- Double Thresholding
- Edge Tracking

# 📸 OpenCV-PhotoLab

A beginner-friendly image editing project built using **Python**, **OpenCV**, **NumPy**, and **Matplotlib** as part of the **AI Builder Series**.

This project demonstrates fundamental image processing operations such as image loading, resizing, cropping, flipping, brightness adjustment, rotation, and saving processed images.

---

## 🚀 Features

- 📂 Load Image
- 🖼️ Display Original Image
- 📊 Display Image Information
- 📐 Resize Image
- ✂️ Crop Image
- 🔄 Horizontal & Vertical Flip
- 🌞 Increase Brightness
- 🌙 Decrease Brightness
- 🔃 Rotate Image (90°, 180°, 270°)
- 💾 Save Processed Images

---

## 🛠️ Technologies Used

- Python 3
- OpenCV

- Matplotlib

## 🎯 Learning Outcomes

After completing this project, you will understand:

- Basic image manipulation using OpenCV
- NumPy slicing for cropping
- Image transformations
- Brightness control using `cv2.convertScaleAbs()`
- Image rotation using `cv2.rotate()`
- Saving processed images using `cv2.imwrite()`
